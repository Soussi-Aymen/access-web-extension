Voice Commands Guide

  • "Search for [term]" — Types query into searchbox and submits.
  • "Click [button or link]" — Clicks matched element by accessible name.
  • "Click [number]" — Clicks element by its transient ID badge (e.g. "Click 2").
  • "Type [text] in [field]" — Fills text into target input field.
  • "Scroll down / Scroll up" — Smoothly scrolls the active page.
  • "What can I do?" — Summarizes available options on this page.
  • "Stop" — Immediately interrupts and cancels voice speech.
